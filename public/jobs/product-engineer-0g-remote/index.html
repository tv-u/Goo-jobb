Job Description

About the Role We’re looking for a product engineer who takes ownership of outcomes, not just assigned tasks. You’ll work across 4–5 products with different technology stacks, identify high-value problems, and carry solutions through design, implementation, testing, documentation, delivery, and operation. What You'll Do Understand our apps and the 0G stack well enough to improve the shared platform, not only one feature. Solve root causes and make durable decisions using shared systems instead of introducing band-aids or duplicated solutions. Own features end-to-end across UI, APIs, server logic, infrastructure, and deployment; do not stop at the layer you are most comfortable in. Build and improve AI-agent infrastructure, including LLM streaming, tool orchestration, sandboxed execution, and security boundaries around untrusted code. Understand wallet-based identity, signing, embedded and external wallets, and server-side authorization without conflating wallet connection with application access. Independently manage dependencies, reviews, blockers, and delivery while raising genuine product decisions and risks early. Raise the bar through meaningful tests, sharp PR reviews, and living documentation that stays true to the product. Be open to adopting new technologies, AI tools, and better working practices. Be reliable enough that when you own an area, the rest of the team can confidently focus on building and expanding other products. Treat “done” as delivered, verified, and operating—not merely coded or test-green. Run what you ship with structured logs, traces, metrics, dashboards, alerts, first-line technical support, optimization, and ongoing support for internal teams and external users. Technical background: Strong end-to-end TypeScript and React experience across client, server, API design, and serverless or edge runtimes. Remix, Next.js, Vite, and Cloudflare Workers experience is valuable. Experience building LLM-powered products beyond basic API calls, including streaming, tool use, prompt pipelines, agent orchestration, or sandboxed execution. Comfortable with web3 application development, wallet authentication, signing, embedded and external wallets, and EVM fundamentals. Hands-on experience with infrastructure as code, CI/CD, containers, production observability, and behavior-driven testing. Our stack includes pnpm, Terraform, GitHub Actions, Docker, Fly.io , Grafana, OpenTelemetry,Prometheus, Vitest, and Playwright.

Job Description

About the job Own the quality gate for the drivers that power Graphcore’s next-generation AI systems. As a Staff System Software Engineer in Test, you will join the Drivers QA team in Cambridge. You will design, build and run tests for complex Linux device drivers, user space libraries and platform tools. Your work will help ensure Graphcore’s driver releases are reliable, robust and production ready. You will shape test strategy, raise engineering standards and solve issues across hardware, firmware, drivers and higher-level software. You will stay deeply hands-on while guiding test infrastructure, coverage and best practice. This role is for someone who wants technical breadth, deep systems work and real ownership of quality. The team and culture The Drivers QA team validates the low-level software that connects Graphcore’s products to real system use. Work spans component testing, system testing, user acceptance and cross-stack validation. You will work closely with development, hardware, firmware, ML stack, Kubernetes and cloud management teams. Decisions are shaped through technical evidence, clear communication and direct ownership. The team moves with purpose, but quality is never treated as an afterthought. You will be expected to speak up, take responsibility and help others raise the bar. What we’re looking for · Deep experience validating Linux kernels and/or device drivers · Strong test development skills in C++ and Python · Experience with CI/CD, build tools and modern automated testing practices · Ability to debug complex cross-layer issues using hardware and software tools · Confidence shaping test strategy, infrastructure and coverage for production software · Clear communication skills, with the judgement to influence technical decisions across teams While we have outlined a set of requirements, we value transferable skills and diverse experiences. We also welcome engineers returning to the profession after a career break, including through returnship routes.
